# Facebook Clone

A Facebook-inspired social media user interface built using **HTML and CSS**. This project was created to practice frontend development and recreate a modern social media layout.

## 📸 Screenshot

<img width="1361" height="623" alt="image" src="https://github.com/user-attachments/assets/be007ccf-9ae4-446f-b05a-fcb7738ed012" />


## 🚀 Features

* Facebook-inspired navigation bar
* Facebook logo and search bar
* Home, Video, Marketplace, Groups, and Explore icons
* Profile, notification, and chat icons
* Stories section
* Multiple story cards
* Story profile pictures
* Hover effects
* Dark theme interface
* Horizontal story scrolling
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Material Symbols
* External image resources

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or additional dependencies are required.
